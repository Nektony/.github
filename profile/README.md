# Nektony

  We build macOS utilities that help you keep your Mac clean, fast, and organized.

  Since 2011, our apps have been trusted by millions of users worldwide.

  ## Our Apps
**[MacCleaner Pro](https://nektony.com/mac-cleaner-pro)**  - All-in-one toolkit to
   clean, optimize, and speed up your Mac 

**[App Cleaner & Uninstaller](https://app-cleaner.com)** - App manager to remove apps, manage extensions and startup items, and track updates in one place.

**[Duplicate File Finder](https://nektony.com/duplicate-finder-remover)** - Find
  and remove duplicate files to free up disk space
